## Repository facts

- #architecture Gitea is a self-hosted all-in-one Git development service: Git hosting/code management, code review, issues, project Kanban, wiki, collaboration, package registry, and CI/CD/Actions. Backend is Go; frontend is Vue/TypeScript; local development uses pure-Go SQLite and requires Git at runtime.
- #architecture Dependency direction is `cmd -> routers -> services -> models -> modules`. `templates/` contains server-rendered templates/mail, `web_src/` frontend TS/Vue/CSS built by Vite into `public/assets/`, and `options/` shipped data/locales. Key routing/context files: `main.go`, `routers/init.go`, `routers/web/web.go`, `routers/api/v1/api.go`, `services/context/context.go`. This fork's Go module path is `gitea.dev`, not upstream `code.gitea.io/gitea`.
- #tooling Minimums in `STUDENTS.md`: Go 1.26.4+, Node 22.18+, pnpm 11+, Git 2.x. Useful setup: `make build`, then `./gitea web` and install with SQLite at `http://localhost:3000`; `make watch` rebuilds continuously. Main checks: `make fmt`, `make lint-go`, `make lint-js`, `make lint-templates`, `make lint-editorconfig`, `make lint`, `make checks`; run `make tidy` after `go.mod` changes. API changes require `make generate-swagger` and validation/checks.
- #testing Test tiers: Go unit tests beside code (`make test-backend`), frontend Vitest (`make test-frontend`), integration (`make test-integration`), Playwright E2E (`make test-e2e`), and migration tests (`make test-migration`). Prefer unit tests; DB-backed Go tests use `unittest.PrepareTestDatabase()` and fixtures; handler tests use `services/contexttest`.
- #contributing `CONTRIBUTING.md` requires formatting/linting/tests, small focused PRs, Conventional Commit PR titles (`type(scope)!: subject`), AI disclosure, and UI PR screenshots (after, plus before for non-new features). Do not add `Co-Authored-By` or `Signed-off-by`; repo instructions require an `Assisted-by: AGENT_NAME:MODEL_VERSION` trailer. New Go files need the current copyright header. Never commit without explicit human approval.
